# What does it mean to become a Frontier Firm?

An interactive white paper (French / English) created, written and designed by **Kevin ANANDOUT**.

> *Qu'est-ce que ça veut dire, devenir une Frontier Firm ?*

This experience shares my view of what becoming a Frontier Firm really means: not simply using more AI, but consciously rethinking how work, decisions and accountability are shared between humans, agents and applications.

## 👉 Read it

- **Online:** https://github.com/KANANDOUT/frontier-firm-whitepaper
- **Offline:** download the repository as a ZIP (**Code → Download ZIP**), unzip it and open `index.html` in any modern browser. Keep `index.html` and the `vendor/` folder together. No installation required.

Eleven chapters, an animated 3D guide, interactive diagrams, light and dark themes, French and English.

## Privacy

The page collects no data. Fonts and the 3D library are bundled with the project, so no request is sent to third-party services when reading it. Your language, theme and reading progress are stored only in your own browser.
